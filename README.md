# Costs
Projeto de estudo de React para gerenciar projetos e seus custos. Dá para cadastrar um projeto com nome, orçamento e categoria, listar e remover. A página de detalhe do projeto, onde entram os serviços, ainda está em andamento.

Feito com React 18, React Router e CSS Modules. O back-end é um `json-server` lendo o `db.json`.

## Execução
```bash
npm install
npm run backend   # API em http://localhost:5000
npm run dev       # front em http://localhost:3000
```
